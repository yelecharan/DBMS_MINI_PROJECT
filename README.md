# Tailgating Detection and Access Control Management System

## Project Overview

The Tailgating Detection and Access Control Management System is a database-driven application designed to manage employee access, monitor entry records, and maintain records of suspected tailgating incidents.

## Objectives

* Maintain employee and access card information.
* Record employee entry and exit activities.
* Store and manage suspected tailgating incidents.
* Provide reports for security officers and administrators.
* Maintain data integrity using database constraints and advanced SQL concepts.

## Technology Stack

* **Relational Database:** PostgreSQL
* **NoSQL Database:** MongoDB
* **Frontend:** Next.js
* **Backend:** API layer

## Project Structure

* `database/` – Database schemas, SQL scripts, and queries.
* `backend/` – Backend API implementation.
* `frontend/` – Next.js application.
* `docs/` – Project documentation and diagrams.
